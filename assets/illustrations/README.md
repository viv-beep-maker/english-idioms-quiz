# Editorial picture clues

Original illustrations for English with Vivien, using a consistent restrained editorial style: fine charcoal lines, muted sage/mint, warm ivory, and small ochre accents. The pictures hint at everyday situations rather than depict literal idiom wordplay. Each visible scene has one main idea and no written target expression.

The fourteen sheets use a three-by-three grid. `illustration-art.js` maps 120 stable clue IDs to individual cells, with descriptions and aspect ratios. The 87 expression defaults remain available; 33 review questions now have separate alternatives. `editorial-clue-012.png` is the selected three-folder alternative for that expression. Unused cells are never displayed. CSS shows exactly one cell, preserving its proportions; original image files are not altered. Every starter question uses a distinct cell. Alternative scenes follow another example context when the review question tests meaning without specifying a scenario.

The visible clue is at most 180 pixels tall on desktop and 158 pixels on phones. The same renderer is used by the quiz and teacher preview. Keeping existing clue IDs preserves saved questions, selected pictures and JSON backups. All art is served locally with the site and works offline when the entire assets folder is retained.

Sheets 11–14 add real-life contextual scenes. The team challenge (`competition/starter-2`) shows two football players contesting the ball; the individual challenge (`competition/starter-10`) shows two women running a close race. The name-recall clue (`clue-049`) now shows two adults at a reunion with a blank name badge. No question wording, definitions, translations, examples, or discussion prompts were changed.

Saved starter review pictures are upgraded once only if their previous default picture and all question content remain untouched. Explicit imported and manually selected alternatives are retained. New editor questions no longer start with an unrelated coffee-table picture.
