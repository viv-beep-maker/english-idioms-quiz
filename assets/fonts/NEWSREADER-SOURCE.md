# Newsreader display font

Official Google Fonts Newsreader Roman variable font, downloaded over verified HTTPS on 2026-11-03.

Source: https://raw.githubusercontent.com/google/fonts/main/ofl/newsreader/Newsreader%5Bopsz%2Cwght%5D.ttf
License: https://raw.githubusercontent.com/google/fonts/main/ofl/newsreader/OFL.txt

WOFF2 SHA-256: 54b31b8f71e1aef31ea2aa9ac53793e078e7532b7bac9e4b082f1f752fff4952

Losslessly repackaged as WOFF2 with fontTools and Brotli; no glyphs, character coverage, font names, or variable axes were changed. Character maps and axes were verified after conversion.
Variable axes: [('wght', 200.0, 400.0, 800.0), ('opsz', 6.0, 18.0, 72.0)].

Self-hosted for offline use. Wordmarks and the home hero use roman Semibold (600). Optical sizing is automatic. Inter handles supporting English text and Pretendard handles Korean. DM Sans files are retained only for older cached versions; the current stylesheet loads only Newsreader, Inter, and Pretendard.
